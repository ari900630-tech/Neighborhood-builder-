# 🏘️ בונה השכונה
משחק בניית שכונה בעברית, RTL, מותאם למחשב ולטלפון.

## משחק
בונים כבישים, בתים, בנייני מגורים, חנויות, פארקים ובית ספר. יש תקציב, אוכלוסייה, ניקוד, מבקרים, שמירה וטעינה.

## שליטה
גרירה מזיזה את המפה. גלגלת או צביטה משנות זום. בוחרים כלי בתחתית ולוחצים על משבצת פנויה.

## Build
`npm run build`
